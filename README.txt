THE DONUT LANDERS: DONUT MATCH
================================
Upload the contents of this folder to the root of a new GitHub repository. Then open Settings -> Pages, choose Deploy from a branch, select main and /(root), and Save.

GAMEPLAY
- Swap neighboring tiles to match 3 or more of the same kind.
- Larger matches and cascades earn bonus points.
- Match Sprinkles, then Glaze, then Chocolate to complete the Landers-in-order objective and earn a 777 Mini Donut Show bonus.
- 30 moves per round. Best score is saved in that browser on that device.
- Sound effects are synthesized in-game. Browser autoplay rules require the player to tap/click before music and sound can start.

IMAGE FILES YOU CAN REPLACE WITHOUT CODING
- assets/images/game-logo.png — optional logo at the top of the game.
- assets/images/sprinkles.png — reserved for character artwork.
- assets/images/glaze.png — reserved for character artwork.
- assets/images/chocolate.png — reserved for character artwork.
- assets/images/mini-donut-show.png — reserved for Mini Donut Show icon artwork.
This starter version uses emoji tiles, so missing optional images do not break the game. Image-based tiles can be wired into a future update using these exact names.

MUSIC MP3 FILENAMES
Upload your own MP3 tracks into assets/music/:
- theme.mp3 — main menu / starting theme.
- theme-1.mp3 — gameplay theme 1.
- theme-2.mp3 — gameplay theme 2.
- theme-3.mp3 — gameplay theme 3.
- theme-4.mp3 — gameplay theme 4.
Tracks are looped. Gameplay tracks are selected in rotation as the game is restarted; to rotate between tracks during one play session, that can be added in a future update. No music is included because you said you will create and upload your own tracks.
