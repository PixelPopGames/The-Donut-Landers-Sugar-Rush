THE DONUT LANDERS — NEON MATCH

UPLOAD TO GITHUB PAGES
1. Extract this ZIP.
2. Upload the contents of the Donut_Landers_7Row_Fix folder directly into the root of your GitHub repository, replacing index.html, style.css, game.js, and README.txt.
3. Commit to the main branch.
4. Open Settings > Pages and confirm publishing from main / (root), then open Visit site.

GAMEPLAY
- Board is 5 columns by 7 rows.
- Tap one tile, then tap an adjacent tile to swap.
- A swap is accepted only when it creates a match of three or more identical pieces horizontally or vertically. Invalid swaps snap back immediately.
- Mix It Up shuffles the board into a playable arrangement.
- Show Hint blinks the two tiles that can be swapped to make a match.
- New Game resets your score and moves.
- Larger matches score more points; the rare 777 special icon has a large jackpot bonus.
- Score and best score use browser local storage when available.

ASSETS
- Optional logo: assets/images/game-logo.png
